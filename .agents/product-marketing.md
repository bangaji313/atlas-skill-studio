# Product marketing context

**Document version:** v1
**Last updated:** 2026-11-02

## Product and audience

Atlas Skill Studio organizes 227 community-developed agent skills into Growth & Social, Creative Production and Engineering Tools. It provides pinned-source assembly and host-specific packages for builders, creators and small teams using Codex, Claude or Antigravity. The distribution is freely available; component licenses and provider costs remain separate.

## Jobs and differentiation

Choose a workflow without maintaining an undifferentiated skill folder; carry a reviewed catalog across supported hosts; trace a skill back to its author and source commit. Alternatives include individually installing upstream skills and maintaining a personal collection. Atlas adds curation, domain grouping, source records, packaging and setup documentation. It does not replace the upstream projects or supply every runtime.

## Voice and claims

Practical, specific, transparent and respectful of maintainers. Explain outcomes before packaging. Use verified counts and concrete examples. Avoid “best,” guaranteed results, guaranteed discoverability, fake user metrics and universal compatibility claims. Primary action: install one relevant studio. Objections to address: optional dependency setup, licenses, provenance and behavior differences across hosts.

## Evidence

227 unique account-discovered skills in the reference installation; 109 OpenMontage tests and small local video/audio checks. New host packaging tests are recorded separately. No testimonials or adoption data are available.

## Learnings

None measured yet. README conversion, stars and installation success are not yet established.
