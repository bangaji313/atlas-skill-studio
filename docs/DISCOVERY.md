# Positioning and GitHub discovery

**Research date:** 2 November 2026. **Method:** Atlas Growth & Social `product-marketing` and `copywriting`, the existing verified catalog, current GitHub topic pages and official discovery guidance.

## Positioning

Atlas Skill Studio is a curated workflow collection for independent builders, creators and small teams who work across marketing, production and engineering. The primary action is to choose one studio and install it. The name keeps the established Atlas identity and states the product category. The README leads with things a user can make, then shows scope, installation and attribution.

Diagnosis A: the brief asks for a new product README with existing brand assets and measured installation evidence. Claims are limited to the actual 227 entrypoints, three studios, pinned-source recipe and recorded verification. There are no invented testimonials, adoption counts, rankings, productivity gains or security certifications.

## Selected repository topics

`agent-skills`, `ai-agents`, `claude-code`, `claude-plugins`, `claude-desktop`, `codex`, `codex-skills`, `antigravity`, `antigravity-skills`, `skill-library`, `developer-tools`, `marketing`, `video-production`, `iot`, `pcb-design`.

Current `agent-skills`, `claude-code-plugins` and `antigravity-skills` topic pages show active projects in this category. These topics describe the real product; they are not a measured ranking of the fastest-growing keywords. GitHub topics support topical discovery; personalized recommendations also depend on a viewer’s activity. No topic, title or badge can guarantee a recommendation, Trending placement or “FYP.”

## Presentation decisions

- Use “227 curated skills / three focused studios” as factual proof, not “the best skills.”
- Lead with workflows: audience question → content plan, brief → editable video, idea → checked engineering artifacts.
- Show the system diagram and a small real render instead of a fabricated application screenshot.
- Make license and host boundaries visible near installation so users know what they receive.
- Use factual badges; do not imply Actions/CI status, universal commercial permission or audited security.
