# Contributing

Report the studio, skill, host/version and a redacted reproduction. Propose upstream fixes to the original maintainer when appropriate and link them here.

Source updates must identify the repository, exact commit, component license, changed files and expected skill counts. Review changes to helper code, executable behavior and asset terms. Keep attribution and preserve source notices. Never commit credentials, dependency environments, stock-media collections or private account/plugin records.

Run `python -m unittest discover -s tests -v`, build the affected studio, and run the relevant native manifest validator. Record the commands and limitations in the change description. Tests and releases run locally; this repository does not use GitHub Actions.
